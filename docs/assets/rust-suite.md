# Rust wedding background suite

Generated with the built-in image generation tool on 19 November 2026. These are original supporting backgrounds for the existing rust invitation. They are integrated through `assets/css/invitation-suite.css`: pressed paper for the story, attire and memories; deep silk for the day, RSVP and dialogs. The original floral hero is retained, with a more prominent matching invitation card.

## Final assets

- `assets/images/rust-pressed-botanicals.jpg` — 218,545 bytes. Same-tone embossed roses on rust cotton paper, calm reading area.
- `assets/images/rust-silk-nocturne.jpg` — 205,447 bytes. Deep rust silk and a cropped rose with a calm central field.

Original tool outputs are preserved under the Codex generated_images directory. Final asset conversion used JPEG quality 86 without changing composition.

## Typography preparation

Bodoni Moda regular/italic and DM Sans regular/medium/semibold are downloaded from official Google Fonts endpoints into `assets/fonts`, with OFL licenses from google/fonts. The page now uses them locally. Italianno is reserved for names, signatures and short expressive accents; Bodoni supplies editorial serif headings/body excerpts, and DM Sans supplies readable controls and metadata. Remote Google Fonts requests are removed.
